XML Student Data Document

XML (Extensible Markup Language) is used to structure, store, and transport data. In an XML document, you define your own custom tags to describe the data elements clearly.

XML Structure Rules:

  • Single Root Element: The document must have one parent tag containing all other tags (e.g. <student_database>).
  • Self-Descriptive Tags: XML tags are custom-defined (e.g., <personal_info>).
  • Case Sensitive: Opening and closing tags must match exactly in case (e.g. <Name> is different from <name>).

1. The XML Code Document (students.xml)

students.xml
<?xml version="1.0" encoding="UTF-8"?> <student_database> <!-- Student 1 Details --> <student roll_no="101"> <personal_info> <name>Gokul K</name> <age>18</age> <email>12gokul2008@gmail.com</email> <phone>9344726109</phone> </personal_info> <academic_details> <department>Computer Science</department> <semester>III</semester> <subjects> <subject code="ITA0202">Web Technology</subject> <subject code="CSA0920">Programming in Java</subject> </subjects> </academic_details> </student> <!-- Student 2 Details --> <student roll_no="102"> <personal_info> <name>Ramkumar M</name> <age>19</age> <email>ramkumar@gmail.com</email> <phone>9876543210</phone> </personal_info> <academic_details> <department>Information Technology</department> <semester>III</semester> <subjects> <subject code="ITA0202">Web Technology</subject> </subjects> </academic_details> </student> </student_database>

2. Data Representation

If we parse the structured XML database above, we get this tabular representation:

Roll No Name Age Department Major Subjects
101 Gokul K 18 Computer Science Web Technology, Programming in Java
102 Ramkumar M 19 Information Technology Web Technology

💡 Beginner XML Tip: XML is purely data storage and format description. Unlike HTML, XML doesn't specify how to render text. To display XML data directly, developers typically use CSS styles, XSLT (XML Stylesheet Language Transitions), or JavaScript to parse and output it inside HTML structures like tables.
