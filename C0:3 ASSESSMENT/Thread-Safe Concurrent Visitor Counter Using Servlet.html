Why thread-safe?

Servlet containers may call one servlet instance from many request threads. An AtomicInteger makes each increment indivisible, so no visitor is lost when requests overlap.

private final AtomicInteger visitors =
        new AtomicInteger(0);

protected void doGet(HttpServletRequest req,
        HttpServletResponse res) {
    int total = visitors.incrementAndGet();
    res.getWriter().println(total);
}
